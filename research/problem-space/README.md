# Problem Space

The problem we are solving and the world it lives in.

Suitable material:

- The official problem statement, copied verbatim, with its ID and source
- Domain background: how the work is done today, by whom, with what tools
- Operating constraints — connectivity, power, hardware, environment, staffing
- Stakeholders and who actually uses the output
- Scope boundaries: what is explicitly *not* being solved

Keep interpretation separate from the source text. Quote the problem statement
exactly, then analyse it in its own section or file.
