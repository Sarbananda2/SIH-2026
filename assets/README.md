# Assets

Diagrams, screenshots, exported images, and other binaries referenced from the
documentation.

| Directory | Contents |
| --- | --- |
| [`diagrams/`](diagrams/) | Architecture and flow diagrams, plus their editable source files |
| [`screenshots/`](screenshots/) | UI captures for docs, demos, and the submission |

Keep files small. Compress screenshots before committing; git stores every
version of a binary forever.

Link every asset from the document that uses it, so it is obvious when one goes
stale.
