# Screenshots

UI captures used in documentation, demos, and the submission.

Name files `screen-context.png` — `dashboard-priority-incidents.png`, not
`Screenshot 2026-08-30 at 21.43.11.png`.

Compress before committing, and re-capture rather than editing an old image when
the UI changes. If a screenshot is used in a document, link it from there so it
is obvious when it goes stale.
