# Diagrams

Architecture, data-flow, and sequence diagrams.

Commit the **editable source** alongside the export (`.excalidraw`, `.drawio`,
or a Mermaid `.mmd` file next to the `.png`/`.svg`). An exported image that
nobody can edit becomes stale and unfixable.

Prefer SVG over PNG for anything with text — it stays legible when zoomed and
diffs less badly.

Name files after what they show: `detection-pipeline.svg`, not `diagram2.svg`.
