# References

External material worth returning to. A curated bookmark list, not a dump.

Suitable material:

- Datasets, with licence and access terms
- Papers, specifications, and standards
- API and hardware documentation
- Tutorials or examples that genuinely helped

Give every entry one line saying why it is here. A bare URL with no context is
noise within a week.

Do not paste large excerpts of third-party material — link to the source and
summarise in your own words.
