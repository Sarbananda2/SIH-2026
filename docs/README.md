# Documentation

How we are building this and why. Research findings live in
[`../research/`](../research/).

| Directory | Contents |
| --- | --- |
| [`architecture/`](architecture/) | System design: components, data flow, deployment |
| [`decisions/`](decisions/) | Architecture Decision Records — why we chose what we chose |
| [`planning/`](planning/) | Scope, milestones, task breakdowns, demo and submission material |
| [`references/`](references/) | External links worth keeping: datasets, papers, docs, APIs |

Binary and visual artifacts do **not** go here — put them in
[`../assets/`](../assets/) and link to them from the relevant document.

## Conventions

- One topic per file. Prefer adding a new file over growing an existing one.
- Use lowercase-kebab-case filenames (`edge-inference-options.md`).
- Date documents that go stale (`Last updated: YYYY-MM-DD`).
- Link between documents with relative paths so they work on GitHub.
