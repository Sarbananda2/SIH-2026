# Planning

Scope, sequencing, and hackathon submission material.

Suitable material:

- Scope for each round or milestone, and what is deliberately out of scope
- Task breakdowns and ownership across the team
- Demo plan and script
- Submission checklists and deadlines
- Retrospective notes

Keep planning documents dated. A stale plan presented as current is worse than
no plan, so mark superseded documents rather than leaving them ambiguous.
